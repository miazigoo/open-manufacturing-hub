# OMH UI i18n Glossary

This glossary keeps product terminology consistent across Russian, English and Chinese UI translations. Domain acronyms such as OMH, OData, XML, JSON, DLQ and API are intentionally preserved.

| Concept | RU | EN | ZH | Notes |
| --- | --- | --- | --- | --- |
| Integration Package | Интеграционный пакет | Integration Package | 集成包 | Installable package boundary. |
| Plugin Store | Plugin Store | Plugin Store | 插件商店 | Product store/catalog name stays recognizable. |
| Runtime | Runtime | Runtime | 运行时 | Keep English in RU where it is a technical product term. |
| Timeline | Timeline | Timeline | Timeline | Trace page for event execution. |
| Queue | Queue | Queue | Queue | Runtime queue term. |
| DLQ | DLQ | DLQ | DLQ | Dead Letter Queue acronym is preserved. |
| Recovery key | Recovery key | Recovery key | 恢复密钥 | Auth package one-time password reset key. |
| Secret | Секрет | Secret | 密钥 | Secure stored value or reference. |
| Endpoint | Endpoint | Endpoint | 端点 | Inbound integration endpoint. |
| Dry Run | Dry Run | Dry Run | Dry Run | Execution mode that does not commit external effects. |
| Package Gate | Package Gate | Package Gate | 软件包网关 | UI guard shown when package is disabled/unavailable. |
| Environment | Environment | Environment | 环境 | Promotion target such as dev/stage/prod. |
| Change Set | Change Set | Change Set | 变更集 | Versioned configuration promotion artifact. |
| Audit Log | Журнал аудита | Audit Log | 审计日志 | Change history and access trace. |
| Business Object | Business Object | Business Object | 业务对象 | Normalized object resolved by runtime. |
| Resolver | Resolver | Resolver | Resolver | Lookup/matching engine component. |
| Transformation | Transform | Transform | 转换 | Payload transformation library item. |
